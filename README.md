# Job Tracker

A responsive job tracking application built with React.js and a REST API to manage and monitor job applications.

## Features

- Add, update, and delete job applications
- Fetch and display job application data dynamically using the Fetch API
- Manage application state with React
- Reusable, component-based architecture
- REST API integration with asynchronous JavaScript and JSON
- CRUD operations for job application records

## Technologies

- React.js
- JavaScript
- HTML/CSS
- REST API
- Fetch API
- JSON
